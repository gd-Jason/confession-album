# 心动纪念册

一个零依赖、可直接打开的告白纪念册页面。它没有使用照片，而是把 7 段告白文案放进独立的拍立得纸质相框；点击相框或使用方向键即可翻阅。

## 使用方式

直接打开 `index.html`，或在本目录启动一个静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 可定制内容

- `index.html`：7 个 `.memory-frame` 中的标题与告白文案。
- `styles.css`：纪念册配色、相框样式、翻页动画和移动端适配。
- `app.js`：点击、键盘、自动翻页及最后一帧的庆祝效果。
